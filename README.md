# Оптимизация операционных и маркетинговых показателей крупного ритейлера (Кейс Sky Crossroads) | SQL + Excel

**Дисклеймер:**
*Проект выполнен в учебных целях на базе синтетического (обезличенного) датасета, предоставленного для анализа бизнес-метрик розничных сетей формата X5 Group / «Перекрёсток». Все коммерческие показатели, названия и персональные данные полностью анонимизированы и не являются коммерческой тайной.*

### Описание проекта:
Комплексный проект (End-to-End кейс) по исследованию операционной эффективности торговых точек в пиковый период (с 1 по 7 сентября). Цель работы — выявить аномалии в скорости обслуживания клиентов, определить их причины, проанализировать программу лояльности и сформировать бизнес-выводы для руководства.

### Что было сделано:
1. **SQL & Сбор данных:** Написание агрегирующих SQL-запросов (JOIN, GROUP BY) для выгрузки сырых логов транзакций из СУБД. Код запросов сохранен в файле `queries.sql`.
2. **Excel & Аналитика:** Очистка данных, расчет метрик (средняя длительность операций по часам, объемы по ТТ) с помощью сводных таблиц и формул.
3. **Маркетинговый анализ:** Оценка эффективности скидочной системы ритейлера. Рассчитана средняя величина скидки (131,6 руб.) и экономия чека для клиента (12,6%).
4. **Инфраструктурный анализ (А/В-тест):** Проведено сравнение производительности серверов (`server` vs `new_server`) при обработке транзакций различных платежных систем.
5. **Визуализация & Презентация:** Построение динамических линейных графиков и комбинированных диаграмм в Excel. Подготовка финальной презентации с защитой аналитических гипотез.

### Ключевые инсайты:
* Обнаружен критический аномальный всплеск длительности операций на ТТ «ул. Щорса, 26/3» в интервале с 3:00 до 6:00 утра. Сформулированы гипотезы о техническом сбое и влиянии маркетинговой акции.
* Оцифрован экономический эффект программы лояльности и обоснована целесообразность перевода ритейлера на обновленные серверные мощности.
