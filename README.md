End-to-End Анализ данных, SQL-моделирование и Автоматизация Отчетности Премиум Фитнес-Клуба (ЗОЖ / ПП)



Комплексный сквозной проект, демонстрирующий интеграцию инструментов \*\*SQL\*\*, \*\*Python (Матстат)\*\* и \*\*Продвинутого Excel\*\* в единую аналитическую экосистему для управления сетью фитнес-клубов.



\## 📊 Структура и Архитектура Кейса



\### 🗄️ Этап 1: Инфраструктурный и Маркетинговый анализ Базы Данных (Файл `queries.sql`)

Реализовано комплексное аналитическое исследование транзакционной базы данных на языке \*\*SQL (PostgreSQL)\*\*:

\* \*\*Операционный анализ:\*\* Выявлены пиковые нагрузки по часам (`EXTRACT(HOUR...)`), рассчитана средняя длительность транзакций в секундах для оптимизации работы серверов.

\* \*\*Маркетинговый анализ:\*\* Оценена эффективность программы лояльности, рассчитан средний чек (`avg\_cheque`), средний размер скидки в рублях и доля использования клиентами касс самообслуживания (`self\_service\_share\_pct`).



\### 🧪 Этап 2: Продуктовая статистика и проверка гипотез (Файл `Premium\_Fitness\_Data\_Core.ipynb`)

Скрипт на Python забирает транзакционные данные фитнес-центра для углубленного анализа:

\* Проведен анализ выручки по категориям клиентов (`Member`, `VIP`) и товарным линейкам (абонементы, СПА, ПП-кафе).

\* Реализована \*\*кастомная функция автоматической оценки взаимосвязей\*\* на базе коэффициентов Пирсона и ранговой корреляции Спирмена.

\* Функция автоматически рассчитывает уровень стат-значимости (`p-value`), сопоставляет его с `alpha=0.05` и генерирует серию диаграмм рассеивания (\*\*Scatter plots\*\*) с автоматическим выводом гипотез (по ТЗ куратора).



\### 📈 Этап 3: Автоматическая генерация финансового календаря (Файл `fitness\_club\_financial\_calendar.xlsx`)

Автоматизирована рутинная ручная сборка отчетов. Скрипт на Python программно формирует готовый Excel-файл:

\* \*\*Динамическая календарная сетка:\*\* Автоматическое распределение ежедневной выручки и расходов по дням и категориям с 19 сентября по 31 октября 2026 года.

\* \*\*Условное форматирование «под капотом»:\*\* Скрипт программно рассчитывает выходные (суббота, воскресенье) и подсвечивает их пастельным розовым цветом для улучшения считываемости (Data Visualization).

\* \*\*Финансовое форматирование:\*\* Нулевые значения автоматически маскируются под бухгалтерские прочерки (`"-"`), а доходы подсвечиваются зеленым цветом.



\## 🛠️ Стек технологий

\* \*\*Базы данных:\*\* SQL (PostgreSQL: агрегатные функции, группировки, функции работы со временем).

\* \*\*Python 3.10+\*\* (Pandas, NumPy, Matplotlib, Seaborn).

\* \*\*Математическая статистика\*\* (SciPy.stats: pearsonr, spearmanr).

\* \*\*Автоматизация офисных пакетов:\*\* Продвинутый Excel (Openpyxl: программное управление стилями, форматами ячеек и формулами `=SUM()`).
